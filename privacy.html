Privacy

TRINKET LAB is a static site. Every tool runs inside your browser tab. There is no backend, no account, and nothing you paste, type, draw or upload is ever transmitted to a server operated by this site.

What stays on your device

Some tools remember your inputs (notes, tasks, links, theme, the last text you pasted) using your browser's localStorage. That data never leaves your browser. You can export it, import it, or wipe it from Settings → Reset everything, or by clearing site data in your browser.

Third-party requests

The page loads two web fonts from Google Fonts, and the Launchpad tool requests small favicon images from Google for the sites you bookmark. Those providers see the ordinary request metadata (your IP address, user agent). Everything else is served from GitHub Pages, which may keep standard server logs.

Permissions

A few tools ask the browser for a capability (camera for Image Forge capture, microphone for the tuner, location for the QR geo preset and Device Scope). Each request is optional, happens only when you press the relevant button, and the data is processed locally.
